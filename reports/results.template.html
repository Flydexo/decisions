05Reading uncertainty

Certainty is a separate signal.

Normalized Shannon entropy measures how concentrated a prediction is. It is distinct from the probability assigned to the chosen option.

What the pilot actually predicted

Mean entropy confidence on shuffled holdout rows. Higher means more concentrated probabilities, not necessarily better answers.

Methods, provenance & reproducibility

Run setup

64 updates × 2 rows; 32 training rows each from AG News, BoolQ, SST-5 and ARC-Challenge. Float32; frozen ModernBERT-base; two trainable transformer layers; 16 attention heads; feedforward width 4,096; context 512; local Trackio logging; atomic head/optimizer checkpoints.

Evaluation

Shuffled holdout uses buffer 2,048 and seed 42, with training-schema truncation. Benchmark source requests use strict complete context. Seven source samples are not the official frozen suite, and no full index is available here.

Checks

22 offline pipeline tests passed, including exact CPU resume and interrupted-optimizer checkpoint protection. Official reproduction-kit integration accepted two supported requests and one context overflow.
